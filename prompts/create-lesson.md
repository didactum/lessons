Paste this to a coding agent in a clone of this repository:

> Read `llms.txt` and follow it exactly. Contribute one lesson on a topic this repository does not have yet: write
> `lessons/<subject>/<slug>.json`, run `python3 scripts/validate_lesson.py` on it until it prints OK, and open one pull
> request containing only that file. Teach the method on a worked example that is different from the problem, never
> state the problem's answer, and write every problem yourself.
